 YouTube Landing Page Clone

A responsive static clone of the YouTube homepage interface built using semantic HTML5 and CSS3. 

🔗 Live Demo: [https://ytdummy.vercel.app/]

 Features
- **Top Navigation:** Sticky header with the YouTube logo, search bar, and Sign In button.
- **Sidebar Menu:** Quick access links for Home, Shorts, Subscriptions, and Library sections (History, Playlists, Watch Later, Liked Videos).
- **Category Filter Bar:** Horizontal topic pills (All, Ambient Music, Hans Zimmer, Mixes, Live, etc.).
- **Responsive Video Grid:** Clean card layout displaying video thumbnails, titles, channel names, view counts, and upload dates.

## 🛠️ Tech Stack
- **HTML5**
- **CSS3** (Flexbox & CSS Grid)

## 🚀 Run Locally
1. Clone the repository:
   ```bash
   git clone https://github.com
   ```
2. Open `index.html` in your browser.
